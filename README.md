# The Limits of Statistical Intelligence · 统计智能的边界

A bilingual (English / 中文) interactive knowledge system on large language models, probability, first principles, causality, world models, and the future of intelligence.

The central question: **Can statistical learning alone produce true understanding?** Modern LLMs write code, translate, and reason — yet they are trained on a single objective, *predict the next token*. This platform explores whether prediction is enough — or whether something is still missing.

A core duality runs through every section: the **Statistical Intelligence Advocate** (prediction is enough) versus the **First-Principles Intelligence Advocate** (prediction is not understanding), color-coded blue and amber throughout.

## Contents

- **Part 1 — What is an LLM?** an interactive Text → Tokens → Vectors → Attention → Prediction pipeline, with a live attention heatmap and next-token distribution.
- **Part 2 — The Statistical Intelligence Hypothesis** — a scaling-law curve with an emergence threshold you can drag past.
- **Part 3 — Correlation vs Causation · Pattern vs Mechanism · Prediction vs Understanding.**
- **Part 4 — Token Relationships vs Reality** — the information-loss ladder from Reality down to the Model.
- **Part 5 — First-Principles Thinking** vs gradient descent, side by side.
- **Part 6 — Causality** — an interactive causal network with an observe/intervene (`do(X)`) toggle.
- **Part 7 — World Models** — language vs physics vs agent models.
- **Part 8 — Can Statistics Lead to First Principles?** — View A vs View B.
- **Part 9 — The Future of AI Architectures** — toward hybrid systems.
- **Part 10 — The Nature of Intelligence** — a clickable radial intelligence map of eight facets.
- **Special — The Symbol Grounding Problem.**
- **The AI Debate System** — two personas argue every topic, round by round.

## Stack

Plain HTML / CSS / vanilla JS — single page, no build step. Bilingual via a JS dictionary + global language toggle (no reload). Every visualization is hand-built with `<canvas>` and SVG: the probability-field hero, attention heatmap, scaling-law curve, causal network, intelligence map, and the debate engine. Fonts: Space Grotesk, Newsreader, JetBrains Mono, Noto Serif SC. Deep-blue scientific-minimalist aesthetic.
